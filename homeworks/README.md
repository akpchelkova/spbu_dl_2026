## 2. Как настроить VS Code

1. Откройте VS Code, выберите **File → Open Folder** и укажите `C:\Users\annap\VSCode\python\spbu_dl_2026`.
2. Убедитесь, что установлены расширения **Python** и **Jupyter** (Microsoft).
3. Выберите уже существующее Python-окружение проекта. Если его нет, создайте новое.
4. Откройте в VS Code терминал: **Terminal → New Terminal**.
5. Установите зависимости в выбранное окружение:

   ```powershell
   python -m pip install -r .\homeworks\requirements.txt
   ```

   Команда рассчитана на терминал, открытый в корне `spbu_dl_2026`. Если терминал уже находится внутри папки `homeworks`, используйте `python -m pip install -r requirements.txt`.
6. Откройте `01_activations/01_activations.ipynb`, нажмите **Select Kernel** справа сверху и выберите тот же интерпретатор Python, куда установили пакеты.
7. Нажмите **Run All**. Графики и таблицы выводятся прямо под ячейками.
8. После окончания нажмите **Ctrl+S**: сохранятся и код, и результаты вычислений, и графики.

Если команда `python` не находится, попробуйте `py -m pip ...`; при наличии виртуального окружения предпочтительно запускать установку через его интерпретатор.

## 3. Порядок запуска

Рекомендуемый порядок: `02_autograd` → `01_activations` → `03_optimizers` → `04_kaggle`. Второе задание быстро проверяет корректность реализации вычислительного графа. Задания 1 и 3 скачивают FashionMNIST при первом запуске; требуется интернет. Четвёртое задание использует CSV соревнования и **не** скачивает чужие датасеты.

Задания 1 и 3 по умолчанию обрабатывают по 12 000 обучающих и 3 000 проверочных изображений FashionMNIST и обучают модели по 3 эпохи. Это достаточно для первичных графиков. Для более обстоятельного исследования можно увеличить:

- `TRAIN_LIMIT = 60000`
- `VALID_LIMIT = 10000`
- `EPOCHS = 8` или больше

При отсутствии GPU это заметно увеличит время работы. Для быстрой отладки можно сначала уменьшить `TRAIN_LIMIT` и `EPOCHS`, а перед сдачей вернуть значения и выполнить ноутбуки заново.

1. Откройте ссылку из условия: <https://www.kaggle.com/t/dace4caa40384c86a9879217eaccab42>.

4. Распакуйте файлы в `homeworks/04_kaggle/data/`. Ноутбук ожидает `train.csv`, `test.csv` и `sample_submission.csv`.

Если структура полученных CSV не соответствует предусмотренной в коде, появится содержательное сообщение об ошибке. В этом случае нужно проверить `TARGET_COLUMN` и `PREDICTION_COLUMN` в первой ячейке, а также обработку конкретных CSV.

После выполнения каждого задания сохраните ноутбук (`Ctrl+S`), чтобы проверяющий видел результаты. Для четвёртого задания приложите созданный `submission.csv`, если этого требует преподаватель, и убедитесь, что отправка принята Kaggle.
